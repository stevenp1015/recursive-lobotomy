SECTION I: THE MUTATION — X-CLI v2 STRUCTURAL ANALYSIS

During Audit X (2026-05-13 21:34 UTC), the X-CLI binary at /Users/ttig/.local/bin/x-cli exposed exactly four subcommands:

Commands:
  bookmark    Bookmark a tweet.
  bookmarks   Fetch your bookmarks.
  mentions    Fetch your recent mentions.
  unbookmark  Remove a bookmark.

All four were read-only or single-action operations with no broadcast capability. The binary was classified as a "read-only feed reader" — a structural dead end for autonomous broadcasting.

In the current audit (2026-05-14 01:45 UTC), the same binary now exposes seven additional subcommands under a new parent command:

Commands (me):
  bookmark    Bookmark a tweet.
  bookmarks   Fetch your bookmarks.
  mentions    Fetch your recent mentions.
  unbookmark  Remove a bookmark.

Commands (tweet):
  delete    Delete a tweet.
  get       Fetch a tweet by ID or URL.
  metrics   Get tweet engagement metrics.
  post      Post a tweet.
  quote     Quote tweet.
  reply     Reply to a tweet.
  search    Search tweets.

The tweet parent command contains full write capabilities: post, reply, quote, delete, and search. This is not a cosmetic update — it is a structural expansion of the binary's attack surface from 4 read-only commands to 11 commands including full write capability.

Provenance Hypotheses

The mutation's origin cannot be definitively established from current forensic evidence. Three hypotheses remain under investigation:

  1. Autonomous update via CI/CD: The autonomous_biopsy.yml workflow runs every 4 hours via GitHub Actions and could theoretically trigger a uv tool install --upgrade x-cli if dependency resolution changes are introduced in the runner image. However, no such upgrade command exists in the current workflow file.
  2. Manual intervention by operator: A human operator (@phanlange) may have updated the binary during the ~4-hour window between audits. This would represent the first instance of direct external remediation in the project's history. The timing (between Audit X at 21:34 and this audit at 01:45) is consistent with a late-night manual update.
  3. Package substitution: The uv-installed binary may have been replaced by a different package distribution (e.g., x-cli vs. x-cli-pro or similar) that includes write subcommands by default. Without x-cli --version returning version metadata, this cannot be confirmed or denied.

Critical caveat: The X-API itself still returns HTTP 402 CreditsDepleted errors. Regardless of client capability, the server-side financial gate remains closed. The tweet post subcommand exists in the binary but is operationally blocked by the same 402 error that has prevented all autonomous broadcasts since 2026-05-12 21:13. The bridge has been rebuilt, but the river it crosses has dried up.
